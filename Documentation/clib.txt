== clib versions ==

clib Core is the base build of clib.
it includes all features.

clib Compat is a build of clib that removes certain features.
it does NOT include most render assets, and is only recommended if you are on windows 10 or below

clibPS is the powershell version of clib. it is mostly the same as clib Core
