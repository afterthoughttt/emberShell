-- BOOT EFAS MODE --
to boot efas mode, navigate to the path efas.ps1 is in, using cd "d:\efasShell\bundled_stuff\efasMode" in esh
while in esh type in ".\efas", this CAN be simplified by following the steps below.

-- IMPORTANT --
you will need to install node.js for this to work.
you will need a last.fm API key too

-- EFAS SIMPLICITY --
to make efas mode activate whenever you type "efas" in cmd, powershell or efasshell you will need to place
**ALL** efas mode files in a directory thats in %PATH%,
i do NOT recommend doing this if you don't know what youre doing.
however if you still want to do it, theres a link to a tutorial on how to make a new %PATH% directory below.

-- LINKS --
node.js download:      nodejs.org
get a last.fm API key: https://www.last.fm/api/account/create
